# outlets/ - rules of engagement

One file per publication Charlie might pitch: `outlets/<slug>.md`, from `_template.md`.

- **Research with sources.** Rates, editors' names and guidelines change; every one gets a URL
  and the date it was checked. An unverified editor name is worse than none.
- **Record what happened.** Each pitch gets a line under `## Pitch history`: date, story slug,
  outcome. That history is what makes the next pitch better.
- **AI policy:** record the outlet's stance when commissioned (`foundation/red-lines.md`,
  line 4).
- Don't create an outlet file speculatively. Create one when Charlie names a target or a
  story's `for:` field needs it.
