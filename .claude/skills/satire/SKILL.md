# Whodle satire batch

**May create:** `brands/satire/YYYY-MM-DD.md`. **Stops at:** the batch, for Charlie to pick.

1. Read `brands/satire/craft.md` (the rules and the checklist), `brands/satire/voice.md`
   (especially Charlie's calibration set) and `brands/satire/posted.md` (don't repeat).
2. Get this week's real football news from the web, preferring the last 24-48 hours. Note the
   real facts each headline will stand on.
3. Write 20 headlines, spread across the six engines in `craft.md`, at least three using the
   outsider's view (the PL from Sydney). Vary the target: owners, governing bodies,
   broadcasters, clubs, fans, FPL, us.
4. Run every headline through the checklist in `craft.md`. Drop what fails; don't argue for it.
5. Write the file as a table: headline, engine, the real story it stands on (with link), and
   one line on where an article would go. Mark your own top five.
6. Reply with your top five only, and the file path for the rest.

When Charlie picks: his picks go into `voice.md`'s calibration set with the date and engine.
When he says one is posted, add it to `posted.md` with date and channel.
