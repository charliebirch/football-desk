# Study a writer

**May create/edit:** `foundation/writers/<writer-slug>.md`. **May not:** edit
`foundation/style-guide.md` unless Charlie picks techniques in this conversation. **Stops at:**
the profile and the "worth trying" table, for Charlie to choose from.

1. Get five pieces by the writer: ones Charlie pastes or points to, or recent public pieces
   you can open. List each with title and URL in the frontmatter.
2. Fill `foundation/writers/_template.md`. Describe technique with short references to where
   it appears ("opens on a single image, then widens: piece 2, para 1"). One short attributed
   quote per piece at most; never paste passages.
3. If `foundation/voice-samples/` has pieces, compare: where Charlie already does this, where
   he differs, what might fit him. Put candidates in `## Worth trying` with a frank fit
   column; not everything a great writer does suits Charlie.
4. Reply with the three most useful techniques and ask which, if any, go into the style guide.
   When he picks, add them to the style guide's adoption table, credited, and log the change
   in `STATUS.md`.

For satire writers, write the profile into `brands/satire/` instead.
