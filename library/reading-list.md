# Reading list

Move a book to `notes/` once it's been read in. Book files Charlie owns go in `books/` on his
Mac; that folder is never committed, so cloud sessions from the phone won't see the books,
only the notes.

## Craft: how to write (foundation stage, read first)

| Book | Author | Use it for |
| --- | --- | --- |
| On Writing Well | William Zinsser | Clarity, cutting clutter; has a chapter on sports writing |
| Writing Tools | Roy Peter Clark | Short, practical techniques, one per chapter; good drill material |
| Essential English for Journalists, Editors and Writers | Harold Evans | Newspaper sentence craft, from a great British editor |
| McIlvanney on Football | Hugh McIlvanney | The benchmark for British football prose; read as a taste source |
